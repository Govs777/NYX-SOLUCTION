# NYX-SOLUCTION
PROJETO NYX

A NYX, é um grupo de TI criado no segundo semestre de 2026. O objetivo do grupo, é desenvolver um projeto para uma empresa com prazo de 5 semestres corridos.

Neste momento já temos a empresa onde prestaremos nossos serviços, ela se chama Arvo.

A Arvo é uma healthtech brasileira, que utiliza Inteligência Artificial e dados para garantir a integridade de pagamentos e a eficiência das auditorias de operadoras de saúde. A empresa atua como parceira do setor para otimizar gastos e garantir a sustentabilidade do ecossistema médico.
